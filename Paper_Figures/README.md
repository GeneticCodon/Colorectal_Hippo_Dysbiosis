# Paper Figures

This folder contains all publication-ready figures generated from the analysis notebooks.

## Figure Organization

All PNG files from the notebooks' `results/figures/` directory should be organized here for the paper manuscript.

### Expected Contents

- **IBD Figures:** Volcano plots, QC plots, pathway analysis visualizations
- **TCGA Figures:** Hippo scoring distributions, enrichment plots, DEG heatmaps
- **Cross-Cohort Figures:** Venn diagrams, overlap comparisons, correlation plots
- **Mechanistic Figures:** Dysbiosis-Hippo relationships, network diagrams, bridging gene visualizations

## Naming Convention

Figures should follow this naming pattern:
```
Figure_[#]_[analysis]_[description].png
```

Example:
- `Figure_1_IBD_VolcanoPlot_UC_vs_Control.png`
- `Figure_2_TCGA_HippoScores_Distribution.png`
- `Figure_3_Overlap_Venn_Diagram.png`
- `Figure_4_Mechanistic_Bridge_Network.png`
